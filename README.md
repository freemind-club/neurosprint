# Нейроспринт

Материалы интенсива **«Нейроспринт»** клуба НейроРенессанс. Ведёт Олег Лаврентьев.

За шесть недель ты собираешь на своём сервере команду AI-помощников для своего бизнеса. Главный помощник — Гермес: он живёт на сервере, настраивается в своём веб-интерфейсе, а каждый день работает с тобой в Telegram. Каждую неделю у него появляется новый сотрудник под тему недели.

**Опыт программирования не нужен.** Сам ты вводишь пару готовых команд установки, всю остальную настройку делает Гермес по готовым сообщениям во вкладке Chat своего веб-интерфейса.

## Как пользоваться

1. Открой урок своей недели и иди по шагам сверху вниз.
2. Блоки с кодом **копируй целиком** кнопкой копирования в правом верхнем углу блока.
3. Блок «Сообщение в Chat» вставляешь во вкладку **Chat** веб-интерфейса Гермеса (`https://agent.твой-домен.ru`). Свёрнутый блок «Если веб-интерфейс не работает» — запасной путь: то же сообщение в чат Гермеса в терминале Netcatty (`hermes`, выход — `/exit`) или команды напрямую. Telegram — для повседневной работы.
4. **Ключи и пароли никогда не отправляй в чат** — ни в Chat Гермеса, ни боту в Telegram, ни в чат потока. Ключ вставляется в поле на странице API Keys или в файл одной командой — всё есть в уроке.
5. Застрял — скрин (без ключей) в чат потока.
