# Бонус: агент сам находит рилсы-выбросы (Apify)

> Нейроспринт · неделя 3 · урок «Контент-агент для коротких видео»
> Данные проверены 11.10.2026. Цены у Apify меняются, перед стартом загляни на страницу актора.

На уроке мы искали выбросы руками: открыли автора, пролистали, нашли ролики, которые выстрелили сильнее обычного. Здесь то же самое, только ролики собирает агент. Ему помогает **Apify**, сервис готовых «сборщиков данных» (они называются *акторы*). Ты называешь автора, актор забирает его последние рилсы с цифрами, а Гермес вычисляет, какие из них выбросы.

---

## Что такое «выброс» и как его считаем

1. Берём **последние 30–50 рилсов** одного автора.
2. Считаем **медиану просмотров**, то есть «обычный» результат этого автора. Медиана, а не среднее: один вирусный ролик среднее задирает, а медиану почти не сдвигает.
3. **Выброс — это рилс, у которого просмотров в 5 раз больше медианы или ещё больше.**

Пример: медиана у автора 8 000 просмотров. Ролик с 40 000 и выше — выброс. Его и разбираем по схеме урока: хук, механика, раскадровка.

Совет: закреплённые ролики лучше исключать, они висят наверху годами и портят картину.

Что отдаёт Reel Scraper по каждому рилсу (основное):
`url` (ссылка), `ownerUsername` (автор), `caption` (подпись), `timestamp` (дата), `videoPlayCount` и `videoViewCount` (просмотры), `likesCount`, `commentsCount`, `videoDuration` (длина в секундах), `videoUrl` (прямая ссылка на видео), `hashtags`, `latestComments` (до 10 комментов). Отдельные платные опции: `sharesCount` (репосты) и расшифровка речи.

Ограничения: собираются **только публичные** аккаунты. Логин и куки не нужны. Цифры фиксируются на момент сбора. Скачанные видео хранятся 3 дня.

## Сколько стоит

- **Бесплатный тариф: $5 в месяц на счёте**, карта не нужна. Кредит обновляется каждый месяц, остаток **не переносится**.
- Reel Scraper на бесплатном тарифе: **≈ $0.0026 за рилс** (то есть ~$2.6 за 1000) плюс $0.001 за каждый запуск. На платных тарифах дешевле, Apify пишет «от $1 за 1000».
- **На $5 бесплатных получится ≈ 1 900 рилсов в месяц, это примерно 35–40 авторов по 50 рилсов.** Для учёбы и регулярного мониторинга нескольких конкурентов хватит с запасом.
- Дорогие опции (на бесплатном тарифе): расшифровка ≈ $0.048, скачать видео ≈ $0.02, счётчик репостов ≈ $0.007 за рилс. **По умолчанию выключай.** Расшифровку делаем только для 3–5 найденных выбросов, а не для всех 50.
- Следующий тариф Starter стоит $19 в месяц.

- Если понадобится платный тариф, нужна зарубежная карта. Как платить за зарубежные сервисы, разбирали отдельно.

## (а) Как подключить Apify к Гермесу — простыми словами

**Шаг 1. Регистрация.** Зайди на [сайт Apify](https://apify.com) и зарегистрируйся. Выбери бесплатный тариф, карта не нужна.

**Шаг 2. Ключ.** В кабинете Apify открой **Settings → API & Integrations**. Там лежит *Personal API token*, длинная строка. Скопируй её.

**Шаг 3. Куда класть ключ. Важно!**
- ✅ Ключ должен лежать **в файле настроек Гермеса** (`~/.hermes/.env`, строка `APIFY_TOKEN=...`). Можно попросить Гермеса создать эту строку, а сам ключ вставить в файл руками.
- ❌ **Не вставляй ключ** в общий чат клуба, в Telegram-группу, в пост, на скриншот или в файл, который выкладываешь на GitHub.
- ❌ Не вставляй его в сообщение Гермесу в группе, где есть другие люди.
- Ключ засветился? В том же разделе API & Integrations создай новый, старый удали.

**Шаг 4. Скажи Гермесу (можно скопировать):**

> Подключи Apify через MCP-сервер `https://mcp.apify.com?tools=apify/instagram-reel-scraper`. Ключ уже лежит у тебя в `.env` в переменной `APIFY_TOKEN`, передавай его в заголовке Authorization. В чат его не выводи. Когда подключишь, проверь на одном аккаунте и покажи мне 3 последних рилса с просмотрами.

**Шаг 5. Рабочая фраза:**

> Возьми последние 50 рилсов аккаунта @имя через Apify, закреплённые пропусти, расшифровку и скачивание видео не включай. Посчитай медиану просмотров и покажи рилсы, у которых просмотров в 5 раз больше медианы: ссылка, просмотры, во сколько раз выше медианы, первая строка подписи. Потом разберём каждый по схеме урока.

Повторяй её для 3–5 авторов из своей ниши, и у тебя готов банк механик.

## (б) Для технарей

### Вызов API (синхронно, сразу получаем данные)

```bash
# Токен — только из переменной окружения, не хардкодить
export APIFY_TOKEN="..."   # берётся из ~/.hermes/.env или менеджера секретов

curl -s -X POST \
  "https://api.apify.com/v2/acts/apify~instagram-reel-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d @input.json > reels.json
```

Токен передаём заголовком `Authorization: Bearer`, Apify считает этот способ безопаснее, чем `?token=` в URL: URL попадает в логи. У синхронного вызова есть лимит по времени (порядка 5 минут). *Точную цифру сверь с документацией.* Если запрос большой, запускай асинхронно (`/runs`) и забирай датасет потом.

### input.json

```json
{
  "username": ["natgeo"],
  "resultsLimit": 50,
  "skipPinnedPosts": true,
  "skipTrialReels": true,
  "includeSharesCount": false,
  "includeTranscript": false,
  "includeDownloadedVideo": false
}
```

`username` принимает ник, ссылку на профиль или на конкретный рилс. Можно передать несколько авторов, тогда медиану нужно считать **по каждому отдельно**. Так и сделано в скрипте ниже.

### Фильтр выбросов: Python

```python
# outliers.py  —  python3 outliers.py reels.json [порог=5]
import json, sys
from statistics import median
from collections import defaultdict

data = json.load(open(sys.argv[1]))
k = float(sys.argv[2]) if len(sys.argv) > 2 else 5

def views(r):
    # videoPlayCount обычно ближе к цифре, которую показывает Instagram;
    # если его нет — берём videoViewCount
    return r.get("videoPlayCount") or r.get("videoViewCount") or 0

by_author = defaultdict(list)
for r in data:
    by_author[r.get("ownerUsername")].append(r)

for author, reels in by_author.items():
    med = median(views(r) for r in reels) or 1
    print(f"\n@{author}: {len(reels)} рилсов, медиана {med:,.0f}")
    for r in sorted(reels, key=views, reverse=True):
        x = views(r) / med
        if x >= k:
            cap = (r.get("caption") or "").split("\n")[0][:80]
            print(f"  {x:4.1f}×  {views(r):>10,}  {r['url']}  {cap}")
```

### То же через jq (один автор)

```bash
jq '[.[] | {url, v: (.videoPlayCount // .videoViewCount // 0)}] as $r
    | ($r | map(.v) | sort | if length%2==1 then .[length/2|floor]
       else (.[length/2-1] + .[length/2]) / 2 end) as $med
    | $r | map(select(.v >= 5*$med) | . + {x: (.v/$med*10|round/10)})
    | sort_by(-.v)' reels.json
```

### Подсказки

- Нужна расшифровка выбросов? Перезапусти актор только по их ссылкам (`username: ["https://www.instagram.com/reel/..."]`) с `includeTranscript: true`. Так дешевле, чем включать расшифровку на все 50.
- По расписанию: в Apify есть Schedules. Можно позвать актор из n8n: в n8n есть готовая интеграция Apify, либо обычный HTTP Request.
- Порог 5× подходит для стабильных авторов. Если у автора мало просмотров или они сильно скачут, попробуй 3×.

## Что неуверенно

- **Работа из РФ.** Официальной позиции Apify по российским пользователям нет. Вывод «бесплатный тариф скорее всего работает, российская карта — нет» сделан по косвенным признакам.
- **`videoPlayCount` или `videoViewCount`.** Оба поля есть в выдаче. Какое из них совпадает с цифрой в приложении, мы не проверяли на живом запуске. Скрипт берёт `videoPlayCount`, а если его нет, `videoViewCount`.
- **Цены.** Сняты с API магазина Apify 11.10.2026 для бесплатного тарифа. Apify их периодически меняет.
- **Лимит времени** синхронного вызова (~300 сек) указан по памяти, не по свежей документации.
- **Подключение MCP к Гермесу.** Гермес умеет подключать HTTP-MCP с заголовком авторизации, это есть в его документации. Конкретно связку с Apify мы не тестировали.
