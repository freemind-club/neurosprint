# Урок 0. Гермес с нуля: от пустого сервера до помощника в Telegram

*Интенсив клуба НейроРенессанс · Нейроспринт · урок 0 · проходится в любой момент, до недели 1*

**Что будет в конце урока.** На твоём сервере живёт помощник — Гермес. Ты пишешь ему в Telegram с телефона, как обычному человеку, и он отвечает. У него есть веб-интерфейс в браузере и доска задач. И всё это работает **бесплатно**: никаких ключей, никаких подписок, никакой карты. Опыт программирования не нужен — ты вводишь две готовые команды, остальное делаешь мышкой и словами.

**Сколько времени.** Весь урок — **40–60 минут**. Если повезёт с интернетом — быстрее. Если будешь ждать домен — до полутора часов.

> **Это тот урок, после которого можно идти в любую неделю интенсива.** Если ты пришёл в поток позже и у тебя ещё ничего не стоит — ты по адресу.

### Главное правило урока

**В терминал ты вводишь ровно две команды.** Первая ставит Гермеса, вторая подключает Telegram. Всё остальное — вопросы на экране, кнопки в браузере и обычные слова.

Команды **копируй кнопкой копирования** в правом верхнем углу блока. Не перепечатывай руками и не пересылай через Word — там команда ломается, а почему, написано в [«если что-то не так»](#если-что-то-не-так).

> **Пароли, токены и коды никогда не отправляй в чат** — ни в чат потока, ни боту, ни на скриншотах. Если делаешь скрин для вопроса — закрой строки с длинными наборами букв и цифр.

## Что нужно до начала

Сервер у тебя уже есть — покупку мы в этом уроке не разбираем. Проверь только, что он подходит:

| Что | Сколько нужно | Почему именно столько |
|---|---|---|
| Операционная система | **Ubuntu 24.04** | под неё написан установщик |
| Память | **2 ГБ — минимум**, 4 ГБ — спокойно | на 2 ГБ обязательно включи файл подкачки в шаге 3, иначе помощник будет падать |
| Свободное место на диске | **минимум 10 ГБ**, с запасом — 40 ГБ | установка весит около 5–6 ГБ: помощник приносит с собой свой Python, свой браузер и ещё кучу всего |
| Доступ | IP-адрес сервера и пароль `root` | пришли на почту от хостинга |
| Telegram | на телефоне | через него ты будешь работать каждый день |
| Компьютер | Windows или Mac | программа Netcatty для установки и браузер |
| Домен *(необязательно)* | любой свой | нужен только для веб-интерфейса, [шаг 8](#шаг-8-веб-интерфейс-твой-офис-из-любой-точки-мира). Есть путь и без домена |

> **Python, Node.js и прочие страшные слова ставить НЕ нужно.** Гермес приносит себе всё своё: свой Python, свой Node, свой браузер, свой ffmpeg. Твоя задача — два раза вставить команду.

> **Если дальше планируешь [неделю 1](../nedelya-1-jev-laya/README.md)** — там в третьей части ставится модель прямо на сервер, и ей нужно **8 ГБ памяти**. Для урока 0 это не обязательно: всё, что мы делаем сегодня, живёт и на 2 ГБ.

**Домен — сделай заранее, если он есть.** В панели, где управляешь доменом, добавь запись **A**: имя `agent`, значение — IP твоего сервера. Получится адрес `agent.твой-домен.ru`. Запись «расходится» по интернету 5–30 минут, поэтому лучше сделать это за полчаса до урока, а не посреди установки.

## Шаг 1. Заходим на сервер через Netcatty

Netcatty — бесплатная программа, чтобы «заходить» на сервер. Это как удалённый рабочий стол, только вместо картинок — текст.

1. Открой [страницу загрузки Netcatty](https://github.com/binaricat/Netcatty/releases/latest). Внизу, в списке файлов, выбери свой:
   - Windows — `Netcatty-…-win-x64.exe`
   - Mac на M1/M2/M3/M4 — `Netcatty-…-mac-arm64.dmg`, Mac на Intel — `Netcatty-…-mac-x64.dmg`
2. Установи и открой. Язык переключается на русский в настройках.
   На Mac, если пишет «не удаётся проверить разработчика»: правой кнопкой по Netcatty в «Программах» → **Открыть** → **Открыть**.
3. Добавь новый хост (кнопка **+** / **New Host**): адрес — IP сервера, пользователь — `root`, пароль — из письма хостинга.
4. Нажми **Подключиться**. Спросит про «fingerprint» / отпечаток ключа — соглашайся, это нормально.

Видишь строку вида `root@что-то:~#` — ты внутри. Всё, что мы будем делать дальше, вставляется сюда.

## Шаг 2. Обновляем систему и ставим две программы

Новый сервер приходит со старыми программами внутри: образ собрали давно, с тех пор вышли обновления и заплатки безопасности. Поэтому сначала обновляем **всю систему целиком**, а заодно ставим две мелкие программы, без которых установщик Гермеса не поедет. Проверять ничего не надо — одна команда делает всё. Что уже стоит, она не сломает.

```
apt update && apt upgrade -y && apt install -y git curl
```

Займёт 3–5 минут, по экрану побегут строки — это нормально.

> 🔴 **Если посреди обновления вылезло цветное окно с вопросом** (розовое или синее, например «какие службы перезапустить» или «что делать с файлом настроек») — **просто жми Enter**. Вариант по умолчанию там всегда безопасный: оставить как есть.

- Если в конце увидишь ошибку про «lock» или «не могу получить блокировку» — свежий сервер в первые минуты сам ставит себе обновления. Подожди 5 минут и повтори ту же команду.
- Если в конце написано про перезагрузку (`System restart required` или `Pending kernel upgrade`) — набери `reboot`, подожди минуту и зайди в Netcatty снова. Ничего не потеряется.

## Шаг 3. Команда 1: ставим Гермеса

Скопируй команду целиком, вставь в Netcatty, нажми Enter:

```
bash <(curl -fsSL https://raw.githubusercontent.com/freemind-club/freemind-setup/main/install.sh) hermes
```

Установка займёт **5–10 минут**: скачается несколько гигабайт. Можно смотреть, как бегут строчки, — это нормально, ничего не сломалось.

По ходу установщик задаст несколько вопросов. **Вот они все, по порядку:**

| Установщик спрашивает | Что делаешь |
|---|---|
| «Добавить своп 4ГБ сейчас? (y/N)» | 🔴 пиши **`y`** и Enter. Просто Enter = **«нет»**, и это ловушка — читай врезку ниже |
| «Выбери 1 или 2 [1]:» | пиши **`1`** и Enter (или просто Enter — это уже выбрано). Это бесплатный Nous Portal |
| Показывает ссылку и код | это [шаг 4](#шаг-4-подключаем-бесплатный-мозг-nous-portal) — не закрывай окно, переходи туда |
| Список моделей | выбери ту, что помечена **●** (по умолчанию). Подробнее — в шаге 4 |
| «Демо-задача для Kanban» | просто Enter. Это учебная задачка для доски, она нужна |
| Ждёт примерно минуту | так и задумано: помощник в этот момент выполняет демо-задачу. Не трогай |
| «Привязать дашборд к домену (https)? (y/N)» | есть домен — **`y`**, нет домена — **`n`**. Что выбрать, разобрано в [шаге 8](#шаг-8-веб-интерфейс-твой-офис-из-любой-точки-мира) |
| «Домен» *(только если ответил y)* | `agent.твой-домен.ru` — тот, что готовил заранее |
| «Email для Let's Encrypt» *(только если y)* | твоя почта. На неё придут письма, если сертификат когда-нибудь будет истекать |
| «Пароль для входа в дашборд (логин admin)» *(только если y)* | 🔴 придумай свой, **только латинские буквы и цифры**, 12 знаков и больше. Читай вторую врезку |

> 🔴 **Первый вопрос — про своп, и на нём ошибаются почти все.**
>
> Своп (он же «файл подкачки») — это **запасная память на диске**. Когда настоящая память кончается, система откладывает часть данных туда и продолжает работать. Без свопа она просто убивает программу, которая не поместилась.
>
> Гермес в момент установки жадный. На сервере с 1–2 ГБ памяти **без свопа он почти гарантированно ляжет** — причём молча: установка просто оборвётся или поставится криво, и бот потом будет отвечать через минуту или умирать.
>
> Поэтому: **увидел вопрос про своп — пиши `y`.** На Enter установщик по умолчанию отвечает «нет» — это ему так положено, но нам не подходит.
>
> Уже установился без свопа? Не страшно. Напиши потом Гермесу в чат: *«добавь своп 4 ГБ и прописи его в fstab, чтобы он остался после перезагрузки»* — он сделает сам.

> 🔴 **Пароль: только латиница и цифры. Апостроф ломает установку.**
>
> Пароль, который ты вводишь для веб-интерфейса, установщик передаёт внутрь служебной команды. Если в пароле есть **апостроф `'`**, кавычки `"`, знак `$`, обратная кавычка `` ` `` или слэш `\` — команда рвётся пополам, и ты увидишь непонятную ошибку про «SyntaxError» или «не удалось сгенерировать хэш пароля». Установка встанет, и догадаться, в чём дело, невозможно.
>
> Поэтому пароль делаем скучный и надёжный: **латинские буквы, цифры, 12+ знаков.** Например `MojGermes2026ok`. Никаких русских букв, никаких знаков препинания.
>
> Если нажмёшь просто Enter — поставится учебный пароль `Hermes_2026!`. Он известен всем, кто читал этот урок. Меняй сразу или придумай свой с самого начала.

Когда всё закончится, установщик напечатает сводку и сохранит её в файл `~/hermes-credentials.txt` на сервере. Там адреса, логин и напоминалки. Пароль оттуда никому не показывай.

> **`hermes: command not found` сразу после установки?** Это не поломка. Терминал просто не перечитал список программ. Выполни:
> ```
> source ~/.bashrc
> ```
> Или проще: закрой окно Netcatty и зайди на сервер заново.

## Шаг 4. Подключаем бесплатный мозг (Nous Portal)

Это происходит **внутри установки**, сразу после вопроса «Выбери 1 или 2». Я выношу его в отдельный шаг, потому что тут человек впервые делает что-то руками в браузере.

На экране появится примерно такое:

```
Starting Hermes login via Nous Portal...
Portal: https://portal.nousresearch.com
1. Open: https://portal.nousresearch.com/manage-subscription?user_code=XXXX-XXXX
2. If prompted, enter code: XXXX-XXXX
Waiting for approval (polling every 1s)...
```

Что делаешь:

1. **Скопируй ссылку из терминала** и открой её в браузере на своём компьютере или телефоне. На сервере браузера нет — сам он открыть её не может, поэтому переносим руками.
2. Войди в свой аккаунт Nous (тот, что заводил в [шаге 0](#шаг-0-аккаунт-nous-заводим-заранее)).
3. Если страница попросит код — введи те же `XXXX-XXXX`, что в терминале.
4. Вернись в терминал. Он сам допишет, что вход удался, и покажет список моделей.

> ⚠️ **Ссылка и код одноразовые и свои при каждом запуске.** Чужой код не подойдёт, а свой никому не давай — это вход в твой аккаунт.

**Выбор модели.** Дальше появится список. Нам нужна **бесплатная** — она помечена кружком **●** как «по умолчанию». Просто нажми Enter, и Гермес возьмёт её.

> **Почему я не пишу имя модели.** Бесплатные модели в Nous меняются: в начале октября была одна, сейчас другая, через месяц будет третья. Если я впишу имя в урок, через две недели ты будешь искать в списке то, чего там нет. Поэтому правило простое: **бери ту, что помечена как бесплатная / по умолчанию.** Захочешь сменить потом — команда `hermes model`.

**Если спросит про Tool Gateway** — покажет список галочек: веб-поиск, картинки, видео, озвучка, браузер. Отметь **веб-поиск и картинки**: на бесплатном тарифе они обычно доступны. Видео на бесплатном, скорее всего, не будет — это нормально, оно нам в уроке 0 не нужно. Экран может выглядеть иначе, чем я описываю, — его мы честно живьём не видели ([см. список](#что-мы-честно-не-проверяли)).

> 🔴 **Главная ловушка на всю жизнь с Гермесом: мозг руками не переключай.**
>
> Если потом захочется сменить провайдера модели — **не трогай настройки руками**. Есть две правильные команды: `hermes portal` (вернуться в бесплатный Nous) и `hermes model` (выбрать модель). Всё.
>
> Почему: когда провайдера меняют вручную, у помощника остаётся **старый адрес** прежнего провайдера. Запрос уходит не туда, а на экране ты видишь «неверный ключ» — хотя ключ правильный, и ты полдня ищешь ошибку не там, где она есть.
>
> Если всё-таки увидел «неверный ключ» — вот лечение, две строки:
> ```
> hermes config get model.base_url
> hermes config unset model.base_url
> ```
> Или просто скажи Гермесу в чат: *«у меня ошибка входа в модель, проверь model.base_url и почини»*.

## Шаг 5. Свой бот в Telegram

Теперь делаем так, чтобы помощник отвечал тебе с телефона. Это пять минут на телефоне, терминал пока не нужен.

1. В Telegram найди **@BotFather** (обязательно с синей галочкой — остальные подделки) и отправь ему `/newbot`.
2. Он спросит **имя** — любое, человеческое: «Мой помощник».
3. Потом спросит **username** — он должен быть свободен и **обязательно кончаться на `bot`**: например `moy_pomoshnik_2026_bot`.
4. BotFather пришлёт **токен** — длинная строка вида `123456789:ABCdef...`. Скопируй её, она понадобится через минуту.
5. Теперь напиши боту **@userinfobot** любое слово. Он пришлёт твой **числовой ID** — что-то вроде `357912468`. Тоже скопируй.

> **Токен бота — это пароль от бота.** Не выкладывай его в чат потока, не показывай на скриншотах. Если он утёк — у BotFather есть команда `/revoke`, она выдаст новый.

**Зачем ID.** Это пропуск: помощник будет отвечать **только тебе**. Любой посторонний, который найдёт твоего бота, получит отказ. Поэтому ID должен быть именно числом, а не твоим `@username` — по username пропуск не работает.

Вернись в Netcatty и вставь вторую (и последнюю) команду:

```
bash <(curl -fsSL https://raw.githubusercontent.com/freemind-club/freemind-setup/main/install.sh) telegram

| Спрашивает | Что делаешь |

## Шаг 7. Проверка «живой»

Открой Telegram, найди своего бота и напиши:

```
Привет! Коротко: какая у тебя модель и какой сегодня день недели?
```

Ответ должен прийти **за пару секунд**.

⚠️ Критерий — **«ответил по делу»**, а не «назвал точное имя модели». Бесплатные модели иногда называют себя как придётся или уклончиво — это не поломка.

**Вторая проверка, самая убедительная.** Напиши ему:

```
Сколько свободного места на диске и сколько свободной памяти? Покажи командами.
```

Он сам выполнит нужные команды на сервере и покажет цифры. Вот это и есть разница между «чат-ботом» и «помощником»: у него есть руки.

Проверь в Netcatty по очереди:

## Шаг 7а. Запасной мозг: если бесплатную модель уберут

**Зачем.** Бесплатные модели не вечные. 27 октября 2026 года Nous без предупреждения сделал платной модель, которая ещё накануне стояла «по умолчанию». У кого не было запасной — помощник просто замолчал. Лечится заранее и **бесплатно**: даём Гермесу список запасных бесплатных моделей. Основная пропадёт — он сам пересядет на следующую по списку и продолжит отвечать.

**Как.** Терминал почти не нужен — просим самого Гермеса. Напиши ему в Telegram или в Chat:

```
Сделай резервную копию ~/.hermes/config.yaml. Потом добавь в него ключ верхнего уровня fallback_providers (НЕ внутрь model:) с тремя запасными моделями по порядку: stepfun/step-3.7-flash:free, ornith/ornith-1.5-122b:free, poolside/laguna-s-2.1:free. У каждой provider: nous и base_url: https://inference-api.nousresearch.com/v1. Покажи, что получилось, и дождись моего «да». Перезапуск шлюза не делай — я сам.
```

Посмотри, что он показал, ответь «да». Потом в Netcatty:

```
hermes gateway restart
hermes fallback list
```

Вторая команда покажет основную модель и три запасные под ней.

> ⚠️ **Тут имена моделей есть — и это исключение.** Это список бесплатных **на 27.10.2026**, он меняется. Свой актуальный смотри командой `hermes model` (там же видно, какие бесплатные) или на портале Nous. **Раз в неделю проверяй, что твоя основная модель всё ещё бесплатная.**

**Как понять, что резерв сработал.** В ответе помощника появится строчка вроде `⚠️ Model fallback: … unavailable (model not found); using stepfun/step-3.7-flash:free via nous.` Это не поломка: основная отвалилась, а помощник не замолчал. Значит, пора выбрать новую основную через `hermes model`.

<details>
<summary><b>Для тех, кто правит руками</b></summary>

В `~/.hermes/config.yaml` (и в конфиге каждого профиля, если они есть) — отдельный ключ на верхнем уровне, не внутри `model:`:

```yaml
fallback_providers:
  - provider: nous
    model: stepfun/step-3.7-flash:free
    base_url: https://inference-api.nousresearch.com/v1
  - provider: nous
    model: ornith/ornith-1.5-122b:free
    base_url: https://inference-api.nousresearch.com/v1
  - provider: nous
    model: poolside/laguna-s-2.1:free
    base_url: https://inference-api.nousresearch.com/v1
```

Порядок важен — пробуются сверху вниз. Перед правкой — копия файла, после — `hermes gateway restart`.

🔴 **Ловушка:** блок `fallback:` **внутри** `model:` Гермес не читает. С виду резерв есть, а на деле нет. Только отдельный ключ `fallback_providers`.

Если меняешь **основную** модель — проверь `hermes config get model.context_length`: число не должно быть больше, чем окно модели (у большинства бесплатных Nous — 262144). Иначе длинная переписка упадёт.

</details>

> **На потом:** все запасные сейчас у того же Nous. Если ляжет весь Nous — резерва не будет. Следующий шаг — второй провайдер (например, бесплатные модели OpenRouter), но это уже не урок 0.

## Шаг 8. Веб-интерфейс: твой офис из любой точки мира

Telegram — для повседневной работы. Но у Гермеса есть ещё **веб-интерфейс**: страница в браузере, где видно вкладку чата без ограничения на длину сообщения, список сотрудников, их навыки и доску задач. Вся настройка в интенсиве делается именно там.

### Почему мы возимся с доменом и шифрованием

Можно было бы просто открыть страницу по адресу сервера — и дело с концом. Но представь, что это за страница: через неё можно **выполнить на твоём сервере что угодно**, а на вкладке с ключами лежат все твои доступы.

Теперь два слова про интернет. Когда ты открываешь адрес, который начинается на `http://` без `s` — всё, что летит туда и обратно, идёт **открытым текстом**. Твой пароль, твои сообщения, твои ключи проходят через чужой Wi-Fi в кафе, через оборудование провайдера, через десяток промежуточных узлов — и каждый из них это видит. Буква `s` в `https://` и означает «зашифровано»: по дороге видно только то, что ты куда-то постучался, а не что именно ты передал.

**Домен нужен ровно для этого.** Сертификат шифрования выдаётся на имя (`agent.твой-домен.ru`), а не на номер. Нет имени — нет сертификата — нет шифрования.

А даёт тебе это вот что: **твой офис открывается из любой точки мира.** С телефона в поезде, с ноутбука в отпуске, с чужого компьютера у родителей. Не только с домашнего компьютера, не только из дома. Это ровно та свобода, за которой люди и ставят помощника на сервер, а не на свой ноутбук.

### Вариант А. Домен и https — так и надо (рекомендую)

Если на [шаге 3](#шаг-3-команда-1-ставим-гермеса) ты ответил `y` и ввёл домен, всё уже готово. Открой в браузере:

```
https://agent.твой-домен.ru
```

Логин `admin`, пароль — тот, что придумал при установке.

Не открылось — скорее всего, запись домена ещё не разошлась (это 5–30 минут) или указывает не на тот IP. Проверь запись и подожди. Установщик честно напишет `SSL не выпущен — DNS не подтверждён`, если не дождался. Повторить потом можно так:

```
certbot --nginx -d agent.твой-домен.ru
```

Пока ждёшь — работай через Telegram, урок это позволяет.

### Вариант Б. Без домена: туннель (если с доменом возиться не хочешь)

Домена нет или не хочешь с ним связываться — ничего страшного. Есть второй честный путь: **туннель**. Ты открываешь защищённую трубу от своего компьютера до сервера, и веб-интерфейс появляется как бы «у тебя на компьютере».

В Netcatty веб-интерфейс так не откроешь — для туннеля нужен обычный терминал. На Mac это программа **Терминал**, на Windows — **PowerShell** (правой кнопкой по «Пуск» → Терминал). Вставь туда:

```
ssh -L 9119:localhost:9119 root@IP-твоего-сервера
```

Введи пароль root. Окно оставь открытым — пока оно открыто, труба работает. Теперь в браузере открой:

```
http://localhost:9119
```

Это адрес на твоём собственном компьютере, поэтому `http` здесь безопасен: шифрует сам туннель.

Минус один, и честный: **с телефона так не зайти**, и из отпуска тоже. Труба работает только с того компьютера, где ты её открыл. Захочешь свободу — заведи домен и вернись к варианту А, это делается в любой момент.

### Вариант В. Просто адрес сервера с номером порта — так НЕ делаем

Ты можешь встретить в интернете совет: «открой `http://IP-сервера:9119` и всё». **Не делай так.** Пароль спросят, но и пароль, и всё, что ты потом увидишь и введёшь, включая вкладку с ключами, поедет по интернету открытым текстом. Это дверь в твой сервер на улице с табличкой «постучите».

### Что внутри

| Вкладка | Зачем |
|---|---|
| **Chat** | тот же помощник, что в Telegram, только в браузере. Сюда вставляют длинные сообщения из уроков: в Telegram есть ограничение 4096 символов, здесь — нет |
| **Kanban** | доска задач. Твоя демо-задача из установки должна лежать в `done` |
| **Profiles** | сотрудники. Пока там только ты один (`default`). Со второй недели тут появятся другие |
| **Skills / MCP / API Keys** | навыки, подключения, ключи. Посмотри и **не трогай** — это темы недель 2 и дальше |

Для урока 0 тебе хватит двух: **Chat** и **Kanban**.

<!-- 📸 скриншот: веб-интерфейс, вкладка Chat -->

<details>
<summary><b>Если при установке ты нажал Enter и получил учебный пароль</b></summary>

Меняем сразу. В Netcatty вставь блок целиком — он спросит новый пароль (символы не появятся, это нормально) и сам перезапустит интерфейс:

```
read -rsp "Новый пароль дашборда: " P; echo; H=$(cd /usr/local/lib/hermes-agent && ./venv/bin/python -c "import sys; from plugins.dashboard_auth.basic import hash_password; print(hash_password(sys.stdin.readline().rstrip()))" <<< "$P"); unset P; if [ -n "$H" ]; then sed -i "s|^HERMES_DASHBOARD_BASIC_AUTH_PASSWORD_HASH=.*|HERMES_DASHBOARD_BASIC_AUTH_PASSWORD_HASH=$H|" ~/.hermes/.env; pkill -f "hermes dashboard"; sleep 2; setsid nohup hermes dashboard --host 0.0.0.0 --port 9119 --no-open > ~/.hermes/dashboard.log 2>&1 < /dev/null & disown; echo "Готово, войди с новым паролем"; else echo "Не вышло, пароль не изменён"; fi
```

Новый пароль — те же правила: **латиница и цифры, без апострофов и кавычек**.

</details>

## Шаг 9. Закрываем лишние двери

Последние две минуты урока, и они про безопасность.

На свежем сервере **межсетевой экран обычно выключен**. Это значит, что внутренняя страница помощника (та, что на порту 9119) может оказаться видна из интернета по открытому `http` — даже если ты честно выбрал вариант А или Б. Закроем.

> 🔴 **Сначала прочитай, потом вставляй — это важно.**
>
> Первая строка блока разрешает вход по SSH. Если включить экран **без неё**, ты отрежешь себе дорогу на свой же сервер и попадёшь туда только через «консоль» в панели хостинга. Поэтому блок вставляется **целиком и именно в этом порядке**.
>
> И на всякий случай: найди в панели своего хостинга кнопку «Консоль» / «VNC» заранее. Это твоя страховка.

```
ufw allow OpenSSH
ufw allow 80/tcp
ufw allow 443/tcp
ufw deny 9119/tcp
ufw --force enable
ufw status
```

Что мы сделали, по-человечески:

- `allow OpenSSH` — оставили открытой дверь, через которую ты заходишь сам;
- `allow 80/tcp` и `allow 443/tcp` — оставили открытым веб-интерфейс по домену и возможность обновлять сертификат;
- `deny 9119/tcp` — закрыли внутреннюю страницу от посторонних (ты сам к ней ходишь через домен или через туннель, им этот порт не нужен);
- `--force enable` — включили экран;
- `status` — показали, что получилось.

В конце ты должен увидеть `Status: active` и список разрешений. Если после этого Netcatty не отвалился — всё правильно.

> **Не хочешь делать это руками** — скажи Гермесу в чат: *«закрой на сервере лишние порты через ufw: оставь SSH, 80 и 443, порт 9119 запрети, экран включи. Сначала покажи мне список команд и дождись моего „да“».* И прочитай список глазами, прежде чем говорить «да».

## Если что-то не так

| Что видишь | Что делать |
|---|---|
| `hermes: command not found` | `source ~/.bashrc`. Не помогло — выйди из Netcatty и зайди снова. Совсем не помогло: `ls ~/.local/bin/hermes`, потом `echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc && source ~/.bashrc` |
| Установка идёт долго и обрывается без понятной ошибки | Не хватило памяти, своп не включён. Поставь своп и повтори: это главная причина падений на 1–2 ГБ |
| На шаге пароля — ошибка про `SyntaxError` или «не удалось сгенерировать хэш» | В пароле апостроф, кавычка, `$`, `` ` `` или `\`. Перезапусти установку и введи пароль **только из латиницы и цифр** |
| Команда «не выполняется», хотя выглядит правильно | Скопирована из русской раскладки (`с`, `е`, `р` вместо латинских) или через Word, который заменил кавычки на «умные». Скопируй **кнопкой копирования** из этого урока заново |
| Установщик сам выбрал вариант и не дал ответить | Запущена старая команда. Скопируй команду из этого урока заново |
| `Could not get lock /var/lib/dpkg/lock` | Сервер сам ставит обновления. Подожди 5 минут и повтори |
| `git is required` / `curl is required` | Пропущен [шаг 2](#шаг-2-обновляем-систему-и-ставим-две-программы): `apt update && apt upgrade -y && apt install -y git curl` |
| Бот молчит на «Привет» | `hermes gateway status`. Не `active` — `hermes gateway restart`. Активен, но молчит — проверь, что в пропуске стоит **число**, а не `@username`: `grep ^TELEGRAM_ALLOWED_USERS ~/.hermes/.env` |
| «неверный ключ» сразу после смены мозга | `hermes config unset model.base_url`, потом проверь ответом. Руками провайдера больше не переключай |
| Ошибка `401` | Вход слетел. `hermes portal` — войди заново |
| Ошибка `429` или «кончилась квота» | Бесплатный пул занят. Подожди пару минут и повтори |
| Ошибка `403` или «unsupported_country` | Запрос идёт не с зарубежного сервера. Проверь, что работаешь **на сервере**, а не на своём домашнем компьютере |
| «No free models currently available» | Бесплатный пул пуст прямо сейчас. Подожди или выполни `hermes portal` заново |
| `This model is no longer free` / ошибка `404` | Твою бесплатную модель сделали платной. Резерв из [шага 7а](#шаг-7а-запасной-мозг-если-бесплатную-модель-уберут) подхватит сам. Резерва нет — `hermes model` и выбери другую бесплатную |
| `hermes model` пишет `requires an interactive terminal` | Команда запущена не из окна Netcatty. Зайди в Netcatty и повтори |
| Веб-интерфейс не открывается по домену | Запись A ещё не разошлась или указывает не туда. Проверь запись, подожди 30 минут. Пока — туннель (вариант Б) или Telegram |
| `hermes gateway status` печатает «service definition is outdated» | Это не поломка, а напоминание. `hermes gateway restart` |
| Всё сломалось, непонятно что | Скрин **без токенов и паролей** в чат потока. Разберёмся |

## Что мы честно не проверяли

Этот урок собран чтением кода установщика и фактами с рабочего сервера. Но **всю установку с нуля на чистом сервере мы живьём не прогоняли** — на рабочем сервере это снесло бы работающего помощника. Поэтому вот список мест, где возможно расхождение с реальностью. **Проверяем вместе на эфире.**

- **Сама установка от начала до конца.** Все шаги выписаны по коду установщика. Порядок вопросов и их формулировки могут отличаться словами.
- **Экраны входа в Nous Portal:** ссылка с кодом, список моделей, галочки Tool Gateway. Текст восстановлен по исходникам, живьём эти экраны не снимались.
- **Какие модели сейчас бесплатные.** Список приходит из портала и меняется. Поэтому в основном потоке урока нет ни одного имени модели — только «та, что помечена как бесплатная». Исключение — запасные модели в [шаге 7а](#шаг-7а-запасной-мозг-если-бесплатную-модель-уберут): список на 27.10.2026, сверяй с `hermes model`.
- **Команда `hermes fallback list`.** Есть в коде Гермеса, сам резерв проверен на живом сервере, а вывод именно этой команды живьём не снимали.
- **Галочки Tool Gateway для бесплатного аккаунта** — есть ли там веб-поиск и картинки. По коду должны быть, экран живьём не видели.
- **Создание бота у BotFather и привязка нового бота.** Шаги по документации; трогать токен рабочего бота было нельзя.
- **Поведение после перезагрузки сервера** — поднимется ли помощник сам. По настройкам должен: служба включена в автозапуск.
- **Команды `ufw` на свежем сервере.** Даны по документации, в правильном порядке. На рабочем сервере экран уже настроен, прогонять было нельзя.
- **Тайминги в минутах.** Взяты из урока 1 и из размеров файлов на диске. Жёстко известно одно: ожидание демо-задачи — ровно 48 секунд.
- **Партнёрская ссылка на портал.** С сервера она отдаёт отказ (защита портала от запросов из дата-центров), из обычного браузера работает. Засчитывается ли приглашение на **бесплатном** тарифе — не проверено.

Если у тебя что-то пошло иначе, чем здесь написано, — **это не ты сломался.** Скрин в чат потока, поправим урок.

## Что умеет Гермес и зачем он тебе

Помощник стоит и отвечает. Теперь пять минут на то, **что у тебя в руках** — чтобы понимать, куда мы идём следующие недели.

### Гермес простыми словами

**Гермес — AI-помощник, который живёт на твоём сервере.** Не в чужом приложении, а у тебя.

- 🕐 **Работает 24/7.** Ноутбук закрыт, телефон в кармане — он на сервере и на связи.
- 🧠 **Запоминает тебя.** Твои предпочтения, твой бизнес, как ты любишь, чтобы тебе отвечали.
- 💬 **Пишешь как человеку.** В Telegram с телефона или в Chat в браузере.
- 🔧 **Не только болтает, а делает.** Читает файлы, ставит задачи по расписанию, работает с сервером.

### Что у него внутри

| Что есть | Что это | Что тебе даёт |
|---|---|---|
| 🧠 **Долгая память** | сам записывает важное о тебе и о деле, помнит прошлые разговоры | не нужно каждый раз объяснять, кто ты и чем занимаешься |
| 📘 **Скиллы (навыки)** | инструкция «как делать вот эту работу» | один раз научил — дальше он делает так же каждый раз |
| 👥 **Профили** | отдельные сотрудники: у каждого своя память, навыки и задачи | Диспетчер не путается с Секретарём, каждый занят своим |
| ⏰ **Задачи по расписанию** | «каждый понедельник в 9:00 сделай…» обычными словами | отчёты и напоминания приходят сами, без твоего пинка |
| 📂 **Файлы и документы** | читает Word, Excel, PDF, пишет свои файлы | закинул документ — получил выжимку |

| 🪟 **Веб-интерфейс** | Chat, Kanban, Profiles, Skills — офис в браузере | видно всё: задачи, сотрудников, навыки |

### Что на самом деле делает команда установки

`install.sh hermes` из репозитория клуба — это обёртка над официальным установщиком Гермеса, которая закрывает несколько известных ям:

1. Проверяет запуск под `root` и переключает `stdin` на `/dev/tty` — иначе при `curl | bash` интерактивные вопросы проглатываются.
2. `unlock_dpkg` — останавливает `unattended-upgrades` и снимает локи, если свежий VPS сам ставит обновления.
3. `ensure_swap 4` — предлагает своп 4 ГБ (дефолт — «нет», отсюда [врезка в шаге 3](#шаг-3-команда-1-ставим-гермеса)).
4. Ставит `uv`, Python 3.11, Node.js 20 LTS — на случай, если они нужны чему-то ещё в системе.
5. Запускает официальный установщик: `curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`. Ему нужны только `git` и `curl`; остальное он приносит сам в `~/.hermes/tools/` — свой Python, свой Node, ripgrep, ffmpeg, chromium, `agent-browser`.
6. Спрашивает про провайдера модели, вызывает `hermes setup --portal` для варианта 1.
7. `hermes status`, `hermes doctor`.
8. `hermes kanban init` → демо-задача → `hermes kanban dispatch` → ожидание **ровно 6 × 8 секунд** → `hermes kanban list`.
9. Вопрос про домен, при `y` — nginx + certbot, реверс-прокси на `127.0.0.1:9119`, ожидание DNS циклами по 15 секунд.
10. `hermes gateway install --system --run-as-user root --start-now --start-on-login` — автозапуск 24/7.
11. Сводка в `~/hermes-credentials.txt` (`chmod 600`).

### Сколько это весит

| Что | Размер |
|---|---|
| `/usr/local/lib/hermes-agent` | ~2,5 ГБ (venv 870 МБ, node_modules 400 МБ, `.git` 857 МБ) |
| `~/.hermes/tools` | ~2,2 ГБ (свой Python, Node, chromium, ffmpeg) |
| кеш `~/.hermes/cache/uv` | ~1 ГБ, можно чистить потом |
| **Итого свободного места** | **минимум 10 ГБ** |

Служба `hermes-gateway.service` в работе держит около 500 МБ памяти — и это с подключёнными внешними серверами. У свежей установки меньше.

### Где что лежит

- Токен входа в Nous: `~/.hermes/auth.json` и `~/.hermes/shared/nous_auth.json`, права `600`. Профильный — `~/.hermes/profiles/<имя>/auth.json`.
- Ключи провайдеров и настройки Telegram: `~/.hermes/.env`, права `600`.
- Исполняемый файл: `~/.local/bin/hermes`.
- Служба шлюза: `hermes-gateway.service`.

### Полезные команды

```bash
hermes --version                  # версия
hermes portal                     # войти в Nous заново (= hermes setup --portal)
hermes portal info                # кто я, какой провайдер, что подключено
hermes model                      # сменить модель интерактивно
hermes config get model.base_url  # посмотреть адрес провайдера
hermes config unset model.base_url  # снести залипший адрес (ловушка «неверный ключ»)
hermes gateway status             # жив ли шлюз
hermes gateway restart            # перезапустить
hermes logs gateway -n 50         # журнал
hermes kanban list                # доска задач
hermes fallback list              # основная модель и запасные
hermes -z "вопрос"                # один вопрос, только ответ, без баннера
hermes doctor                     # самодиагностика
```

### Почему `--insecure` не поможет

У команды `hermes dashboard` по умолчанию адрес `127.0.0.1`; это установщик клуба принудительно ставит `0.0.0.0`, чтобы в него мог прийти nginx. Флаг `--insecure` с июня 2026 ничего не делает: публичная привязка **всегда** требует провайдера авторизации. То есть снять пароль с веб-интерфейса нельзя даже специально — и это правильно.

Опасность не в самой привязке к `0.0.0.0`, а в комбинации «`0.0.0.0` + выключенный межсетевой экран». Установщики делают `ufw allow`, но **не включают** `ufw` — а на свежем VPS он обычно выключен, и команда просто тихо ничего не делает. Отсюда [шаг 9](#шаг-9-закрываем-лишние-двери).

### Что в урок сознательно не попало

- Второй провайдер в резерве (например, OpenRouter) — на случай, если ляжет весь Nous. Пока все запасные из [шага 7а](#шаг-7а-запасной-мозг-если-бесплатную-модель-уберут) у одного Nous.
- Перенос входа Nous между профилями — работает ненадёжно, новичку с одним профилем не нужно.
- `hermes pairing` — коды доступа для других людей к твоему боту. В уроке 0 в пропуске только ты.
- Групповые чаты: по умолчанию бот в группе видит только обращения к себе. Чтобы видел всё — `@BotFather → Bot Settings → Group Privacy` выключить, потом удалить и заново добавить бота в группу.

</details>
